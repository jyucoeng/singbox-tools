#  singbox一键安装脚本、socks5一键脚本、mtp一键脚本

### 🚀 在线生成安装命令：[singbox.dingdang.de5.net](https://singbox.dingdang.de5.net/)

**打开就能用**：勾选要装的协议、填好端口 / 域名 / SNI，页面直接给出可复制的 `bash <(curl -Ls ...)` 命令，粘到服务器执行即可。

> 源码：[singbox-tools-interface](https://github.com/jyucoeng/singbox-tools-interface)（也可自行部署，换成你自己的域名访问）。
> 节点汇聚项目：[sub_merge](https://github.com/jyucoeng/sub_merge)，部署后用自己的域名汇聚所有机器的节点。
